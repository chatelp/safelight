# Design assets

Icons, color tokens and the README banner for Safelight. The design language
(colors, type, icon rules, menu bar states, tone of voice) is documented in
[docs/DESIGN.md](../../docs/DESIGN.md).

- `masters/` holds the SVG sources. Edit these.
- `tokens.json` holds the color tokens. Edit this.
- Everything else is generated by `scripts/render_icons.py`:
  - `Assets.xcassets/`: the app icon, the menu bar template images and the
    color sets, ready for the Xcode project;
  - `Safelight.icns`, `app-icon-1024.png` and `banner.png`;
  - `tokens.css`.

To regenerate, run this from the repository root (it needs Cairo:
`brew install cairo`):

```bash
uv run python scripts/render_icons.py
```
